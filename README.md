# DeepBalance

A small desktop application for monitoring Deepseek API balance.
All by my own! yet so simple...

## Features

- Query current API balance
- Save balance data locally
- Query balance every 5 minutes, automatically
- Display balance data as a line chart

## Requirements

- Python 3
- tkinter
- matplotlib

## How to use

Run in bash: python main.py
Enter your DeepSeek API key in the blanket and click 'Sure'.
You can read the history data in 'history.json'.
